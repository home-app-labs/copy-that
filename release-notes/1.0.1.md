- Colour preview: copy a hex colour such as `#FFB833` and its card shows the colour itself, with the RGB values underneath
- A new icon: a stack of copied cards, the front one ticked

**Install:** download `Copy-That.pkg` and open it. macOS blocks it the first time because the app is not signed with a paid Apple developer certificate: open System Settings → Privacy & Security and click "Open Anyway". Pictures of each step are on https://homeapplabs.com/install/

Updating from 1.0.0: run the new installer. Your history and snippets stay. macOS asks for the Accessibility permission again: remove Copy That from the list in System Settings → Privacy & Security → Accessibility and add it back.

Works on macOS 14 or later, on Apple Silicon and Intel Macs.
